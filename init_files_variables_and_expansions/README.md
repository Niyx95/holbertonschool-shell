## Overview
This directory contains scripts regarding variables, files and expansions

### 0-alias
- script that maps a command to another

### 1_hello_you
- script that print a greeting to the user

### 2-path
- script that adds a directory to the end of the PATH variable

### 3-paths
- script that count every directory in PATH

### 4-golbal_variables
- script that prints environment variables to stdout

### 5-local_variables
- script that print out all local, environment and function variables

### 6-create_local_variable
- script that creates a new local variable

### 7-create_global_variable
- script that creates a global variable

### 8-true-knowledge
- script that adds a environment variable to a value

### 9-divide_and_rule
- script that prints the result of a division

### 10-love_exponent_breath
- script that prints the result of a exponent calculation

### 11-binary_to_decimal
- script that converts a binary to a decimal

### 12-combination
- script that print a combination of rules to stdout

### 13-print_float
- script that print out a float number, input as a decimal

### 14-decimal_to_hexadecimal
- script that converts a decimal number to a hexadecimal
