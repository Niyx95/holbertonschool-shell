## Overview

This directory is about input/output scripts from Holberton School Australia

### 0_Hello_World
- script that sends Hello, World to stdout

### 1-Confused_smily
- script that prints a Confused_smily to stdout

### 2_hellofile
- script that print the content of /etc/passwd

### 3_twofiles
- script that print content of /etc/passwd and /etc/hosts
