## Overview

This directory is about input/output scripts from Holberton School Australia

### 0_Hello_World
- script that sends Hello, World to stdout

### 1-Confused_smily
- script that prints a Confused_smily to stdout

### 2-hellofile
- script that print the content of /etc/passwd

### 3-twofiles
- script that print content of /etc/passwd and /etc/hosts

### 4-lastlines
- script that displays the last 10 lines of a file

### 5-firstlines
- script that prints the first 10 lines of a file

### 6-thirdline
- script that prints only the third line of a document

### 7-file
- script that creates a strange name directory

### 8-cwd_state
- script that inputs ls -la and redirects to a new or existing command overwriting it

### 9-duplicate_last_line
- script that duplicates the last line of a file

### 10-no_more_js
- script that find all javascript files and deletes it

### 11-directories
- script that find all directories and subdirectories and counts them

### 12-newest_files
- script that displays and sorts files from oldest to newest

### 13-unique
- script that takes file as a input, print and sort unique char

### 14-findthatfile
- script that looks for a word in a specific file

### 15-countthatword
- script that greps a specific word and count how many times it appears

### 16-whatsnext
- script that greps a word and prints 3 following lines

### 17-hidethatword
- script that hides a specific word from the output

### 18-letteronly
- script that display line starting with a letter

### 19-AZ
- script that replaces A and Z char with c and e

### 20-hiago
- script that deletes specific char from the final output

### 21-reverse
- script that reverse the input given

### 22-users_and_home
- script that takes only specific fields and sorts them
