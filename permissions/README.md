## Overview
This directory contains small permissions scripts regards Linux permissions

### 0-iam-betty
- script that switches current user to betty

### 1-who_am_i
- script that print current user

### 2-groups
- script that print the groups of the current active user

### 3-new_owner
- script that changes the owner of the file hello

### 4-empty
- script that creates a new empty file

### 5-execute
- script that gives execute permission to the owner of file hello

### 6-multiple_permissions
- script that gives multiple perissions to a file

### 7-everybody
- script that gives execute permissions to everybody 

### 8-James_Bond
- script that gives no permisson at all to owner and groups, gives full permission to other users

### 9-John_Doe
- script that changes mode to a specific file

### 10-mirror_permissions
- script that mirrors permissions

### 11-directories_permissions
- script that changes permissions to directories and all subdirecotories

### 12-directory_pemissions
- script that created a directory with specific permissions

### 13-change_group
- script that chnage group ownership of a file

### 14-owner_and_group
- script that changes owner and group permissions

### 15-symbolic_link
- script that changes permissions on a symlink

### 16-if_only
- script that changes only owner if current owner is a specific user
